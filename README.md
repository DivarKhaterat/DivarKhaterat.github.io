# دیوار خاطرات سربندر

## اجرا روی سیستم خودت
1. Node.js نسخه ۱۸ یا بالاتر نصب کن.
2. داخل پوشه‌ی پروژه بزن: `npm install` و بعد `npm start` (همون `node server.js`)
3. آدرس `http://localhost:3000` رو باز کن.

## روی سرور / هاست
- فایل‌ها رو آپلود کن و `node server.js` رو اجرا کن (برای ماندگاری از pm2 یا systemd استفاده کن).
- پورت رو با متغیر `PORT` عوض کن. پشت nginx هم راحت کار می‌کنه.
- هاست‌های اشتراکی cPanel با «Setup Node.js App» کار می‌کنن؛ فایل شروع: `server.js`.

## روی Netlify
Netlify سرور همیشه‌روشن اجرا نمی‌کنه، برای همین `server.js` اونجا مستقیم بالا نمیاد. به‌جاش:
- فایل‌های `public` به‌صورت ثابت سرو می‌شن (تنظیم در `netlify.toml`).
- همون API (`/api/memories`، لایک و نظر) با همون قوانین در `netlify/functions/api.mts` اجرا می‌شه.
- داده‌ها تو دیتابیس Netlify (Postgres) ذخیره می‌شن؛ جدول‌ها در `db/schema.ts` تعریف شدن و موقع دیپلوی خودکار ساخته می‌شن.

## ذخیره‌سازی
خاطره‌ها تو `data/memories.json` ذخیره می‌شن. از همین فایل پشتیبان بگیر.

## محافظت‌ها
- حداکثر ۱۰۰ خاطره در ۱۰ دقیقه برای هر آی‌پی
- طول متن ۱۵۰۰ و اسم ۳۰ کاراکتر، فقط عکس jpeg کوچک
- متن‌ها فقط به‌صورت متن ساده نمایش داده می‌شن (بدون خطر XSS)
- لایک (هر نفر یک بار برای هر خاطره) و نظر (حداکثر ۵۰۰ کاراکتر، ۳۰۰ نظر برای هر خاطره)
